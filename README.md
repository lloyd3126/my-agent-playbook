## X

### 串文發布

#### 目的

將較長的內容拆成容易閱讀的 X 串文，而不是全部放在同一則留言中。

#### 發布流程

1. 先回覆目標貼文，發布簡短的開場文字。
2. 回覆自己的開場文字，發布 `[1 / 3]`。
3. 回覆 `[1 / 3]`，發布 `[2 / 3]`。
4. 回覆 `[2 / 3]`，發布 `[3 / 3]`。

#### 檢查點

- 發布第一則前，先讓使用者確認內容。
- 若使用者要求逐則檢查，每發布一則後就暫停。
- 若使用者已確認內容並要求接續完成，可連續發布剩餘內容。

#### 限制

- 不要將多個段落放在同一則留言中。
- 不要加入分隔線。
- 開場文字不需要編號。
