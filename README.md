## X

### 串文發布

#### 目的

將較長的內容拆成容易閱讀的 X 串文，而不是全部放在同一則留言中。

#### 發布流程

1. 先回覆目標貼文，發布簡短的開場文字。
2. 回覆自己的開場文字，發布 `[1 / 3]`。
3. 回覆 `[1 / 3]`，發布 `[2 / 3]`。
4. 回覆 `[2 / 3]`，發布 `[3 / 3]`。

#### 檢查點

- 發布第一則前，先讓使用者確認內容。
- 若使用者要求逐則檢查，每發布一則後就暫停。
- 若使用者已確認內容並要求接續完成，可連續發布剩餘內容。

#### 限制

- 不要將多個段落放在同一則留言中。
- 不要加入分隔線。
- 開場文字不需要編號。

## 財報狗

### 產業報告研究

#### 研究目的

透過財報狗的產業報告、公司頁面與產業鏈資料，建立有來源、可追溯的產業理解。

#### 研究流程

1. 先確認研究主題、產業與時間範圍。
2. 優先閱讀指定期間內最新的產業報告。
3. 延伸閱讀相關報告，例如 HDD、NAND、DRAM 與設備。
4. 將內容分成：
   - 報告中的客觀事實
   - 財報狗的分析判斷
   - Agent 根據資料做出的推論
5. 對照產業鏈、公司名稱、股票代號與上下游關係。
6. 用繁體中文整理核心結論、驅動因素、風險與相關公司。
7. 附上報告連結，讓使用者可以回頭查閱。

#### 互動方式

- 使用者問題明確時，直接開始查找，不重複詢問已知資訊。
- 研究過程中先蒐集多份資料，再形成結論。
- 不把 Agent 的推論說成財報狗原文。
- 若報告內容不足，明確標示不確定性。
- 涉及投資判斷時，區分產業分析與個人投資建議。
- 使用者只要求查看時，不改變收藏、追蹤或其他帳戶狀態。
- 需要登入時，沿用現有瀏覽器工作階段，不要求使用者提供密碼。
