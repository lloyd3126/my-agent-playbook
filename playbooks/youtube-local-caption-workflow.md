# YouTube 本機字幕流程 v1

## 目的

將使用者提供的 YouTube 影片整理成可在本機播放、可切換繁體中文翻譯與英文字幕的播放器頁面。

## 流程

1. 確認影片網址與使用者要處理的語言。
2. 用 `yt-dlp` 取得自動字幕清單；優先下載原始英文字幕與繁體中文自動翻譯字幕。
3. 下載影片 MP4；另外下載僅音訊檔供本機轉錄，不把中間檔提交到模板專案。
4. 使用專案內的 Python 3.11 虛擬環境與 Whisper `turbo` 模型進行本機轉錄。
5. 將字幕整理成 VTT／SRT，檢查時間戳、語言與檔案完整性。
6. 下載 `templates/youtube-caption-player/index.html` 作為播放器模板。
7. 將素材重新命名為模板固定檔名：
   - `video.mp4`
   - `captions.zh-TW.vtt`
   - `captions.en.vtt`
8. 以本機 HTTP 伺服器開啟頁面，測試播放、字幕同步與語言切換。

## 產物與命名

每支影片的工作資料夾可以保留原始檔名；交給模板時才轉成固定檔名。模板不內含特定影片、影片 ID、下載內容或模型檔案。

## 驗證檢查點

- MP4 可以在 Plyr 中載入，且影片長度合理。
- VTT 可以讀取，至少包含一個有效 cue 與時間戳。
- 繁體字幕在播放、跳轉與拖曳時間軸時同步更新。
- 英文字幕可由選單切換。
- 使用 `http://localhost` 開啟，不使用 `file://`。
- 若 Apple Silicon 的 MPS／Torch 組合不穩定，允許退回 CPU 完成轉錄，並在結果中說明。

## 安全與權限

- 只處理使用者提供且有權處理的影片內容。
- 預設不將下載的影片、音訊、字幕或 Whisper 模型提交到此 playbook。
- 下載字幕與媒體前，清楚區分「字幕下載」與「影片／音訊下載」。
- 任何外部發布或帳號互動都需要額外明確授權；本流程只建立本機檔案與播放器。
