# 財報狗公司與產業研究

## 目的與界線

利用財報狗的產業報告、公司頁面、財務指標與產業鏈資訊，建立有來源、可回查的公司或產業理解。輸出是研究整理，不等同個人投資建議。

預設只讀，不修改收藏、追蹤、通知、方案或其他帳戶狀態。

## 開始前確認

- 公司名稱、股票代號或產業主題
- 市場與研究期間
- 希望回答的問題，例如成長驅動、循環位置、上下游或風險
- 是否有使用者指定的報告、公司或比較對象
- 需要快速摘要、完整報告或可持續維護的 knowledge 文件

## 環境確認與啟用

這個流程通常不需要本機程式套件。需要能讀取財報狗的瀏覽器，以及使用者有權存取的內容。

1. 確認 Agent 是否能控制內建瀏覽器或 Chrome 分頁。
2. 開啟 <https://statementdog.com/>，確認網站、公司搜尋與報告頁可用。
3. 如果內容需要會員權限，由使用者直接在網站登入；Agent 不索取密碼、cookie 或驗證碼。
4. 確認目前方案能看到哪些資料，付費牆後內容不可假裝已讀。
5. 若沒有瀏覽器控制能力，Agent 可以整理使用者提供的網址、截圖或匯出資料，但必須標示來源範圍。

若主機尚未啟用瀏覽器控制，使用者依主機應用程式介面啟用；不需要為此安裝 Python、爬蟲套件或非官方財報狗工具。

## 首次研究流程

1. 記錄公司、代號、產業、查詢日期與研究範圍。
2. 找到正確公司頁，核對市場、代號與同名公司。
3. 優先閱讀指定期間內最新且直接相關的產業報告。
4. 延伸閱讀上下游、同業與相鄰主題；例如儲存產業可對照 HDD、NAND、DRAM 與設備。
5. 擷取每個結論所需的報告標題、日期、直接連結與資料期間。
6. 把內容分成：
   - 財務數據或報告中的可核對事實
   - 財報狗作者的分析判斷
   - Agent 根據多份來源做出的推論
7. 對照產業鏈、公司名稱、股票代號與上下游關係。
8. 檢查資料期間是否一致，避免把月營收、季度財報和即時股價混成同一時間點。
9. 用繁體中文整理核心結論、驅動因素、風險、反證與相關公司，並附直接來源。

## 研究品質檢查

- [ ] 公司與股票代號正確
- [ ] 每項重要數據都有期間、單位與來源
- [ ] 最新報告與歷史報告沒有混淆
- [ ] 報告原文觀點和 Agent 推論分開
- [ ] 付費牆、登入限制與缺漏已揭露
- [ ] 投資相關內容沒有被描述成保證或個人化建議

## 持續使用與教學

下次可直接說：

> 依照財報狗研究 playbook，研究台積電最近兩季的營運驅動與風險，先核對代號與資料期間，附上每份報告連結。

> 更新上次的記憶體產業研究，只比較新報告造成的結論變化，不重做全部背景。

持續更新時，先讀既有報告或 knowledge 文件，列出新增來源、資料截止日、結論變化與仍未解決的問題。網站改版時重新確認頁面結構，不依賴過時 selector。

## 故障與限制

- 找不到公司：用代號、交易市場和公司全名交叉核對。
- 內容被鎖：說明無法存取的區段，不以搜尋摘要補成完整原文。
- 圖表無法直接取得：記錄畫面顯示的期間、單位和標題；若使用截圖或 OCR，標記可能誤差。
- 資料互相衝突：保留兩邊來源與日期，說明可能是資料更新或定義不同，不任意挑一個。

## 停用與完整移除

這個流程沒有必需的本機套件。要完整停止：

1. 停止任何排程更新或監看。
2. 關閉財報狗分頁；需要時由使用者自行登出。
3. 在主機應用程式停用瀏覽器控制連線；若另裝擴充功能，依官方程序移除。
4. 研究報告和 knowledge 文件預設保留；只有使用者指定精確檔案並確認後才刪除。
5. 不刪除財報狗帳號、收藏或訂閱，除非使用者另行明確要求並確認外部影響。
