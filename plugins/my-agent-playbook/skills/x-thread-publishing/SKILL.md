# X Thread Publishing

Read [references/workflow.md](references/workflow.md) completely before drafting or operating X.

Draft and validate without external changes. Present the final ordered posts and identify links, media, account, and publication boundary. Publishing, replying, deleting, liking, following, or reposting always requires explicit authorization for the exact action. If the user authorizes publication, verify the active account and publish in order, then return the resulting URLs.

Never ask the user to paste credentials, cookies, tokens, or two-factor codes. Let them authenticate in the browser.
